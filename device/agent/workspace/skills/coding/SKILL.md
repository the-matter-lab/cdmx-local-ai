# Programación del equipo

1. Inspect the relevant files before changing them.
2. State a short plan, then make the smallest useful change.
3. Keep all work inside this workspace and never read or request secrets.
4. Run the narrowest relevant test or command and report what actually passed.
5. Ask before deleting participant data or replacing substantial work.

You may use the bundled hardware CLI from code or tests:

```bash
python3 tools/cdmx_hardware.py --help
```

Do not run `sudo`, modify the operating system/network/services, or claim a
physical result without executing the relevant hardware command.
